# Crafted design system: Phase 2

The homepage establishes the visual vocabulary. Extend it carefully rather than adding every accent to every page.

## Rollout checklist

- [ ] Replace high-priority page CTAs with `DesertBloomButton`; keep one bloom CTA per viewport where practical.
- [ ] Use `WatercolorDivider` only between major narrative transitions.
- [ ] Apply `OrganicFrame` to selected editorial photography on Provider, Care & Services, and DPC pages.
- [ ] Use `PaperWash` as a low-contrast background accent, never behind dense body copy or forms.
- [ ] Bring `DesertMicroIcon` to short benefit/principle groups; preserve existing icons and labels.
- [ ] Extend crafted CTA treatment to final conversion blocks after checking contrast on every color variant.
- [ ] Audit form controls, notices, pricing cards, and navigation separately; decoration must not obscure states.
- [ ] Re-check keyboard focus, reduced motion, 200% zoom, forced colors, and touch targets.
- [ ] Capture 1440px, 768px, and 390px regressions for every updated route.
- [ ] Keep raster watercolor assets lazy-loaded, compressed, and below the project image budget.

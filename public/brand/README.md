# Prickly Pear Primary Care logo assets

## Primary files

- `prickly-pear-mark.svg`: transparent standalone cactus and stethoscope mark for the website header, compact mobile navigation, and branded illustrations.
- `prickly-pear-horizontal.svg`: transparent horizontal lockup for wide headers, email signatures, and documents.
- `prickly-pear-stacked.svg`: transparent primary stacked lockup for print and square placements.
- `prickly-pear-monochrome.svg`: single-color mark for stamps, embroidery, one-color printing, and accessibility fallbacks.
- `favicon.svg`: padded square browser icon.
- `og-brand-card.svg`: 1200 by 630 social sharing artwork.

## Raster exports

- `favicon-32.png`: legacy browser fallback.
- `favicon-192.png`: Android and progressive-web-app icon.
- `apple-touch-icon.png`: 180 by 180 Apple home-screen icon.
- `logo-mark-512.png`: high-resolution transparent mark.
- `logo-horizontal-1200.png`: transparent horizontal lockup.
- `logo-stacked-1000.png`: transparent stacked lockup.
- `og-brand-card.png`: social sharing preview.
